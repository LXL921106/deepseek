# 组格式（A 方案主干）· 七段式模板

> **这是本技能的输出主干。** 一个「组」= 一次平台生成（6—15 秒，1 个文件）。
> 组长由**剧情断点**决定，不由时长凑。
> 门禁：`scripts/check_groups.py`。规则 ID 见 [rule-tiers.md](rule-tiers.md)。

## 为什么是七段

| 段 | 作用 | 少了会怎样 |
|---|---|---|
| **头（一行）** | 画幅 · 质感 · 光线 · 地点 · 时间 · 镜数 · 生成秒数 | 平台参数没依据 |
| **参考** | 本组**全部**出场的人与物，带上传编号 | **正文出现的人没图** → 长相漂移／多出一个人（`GRP-01`） |
| **起始** | **只写状态**，不写画面 | 描述会**泄漏成镜1 的画面**（实测：写了志远抱衣服，镜1 就拍了他 2.33 秒） |
| **镜N** | 起—止秒 · 景别 · 机位 · 可见动作 · `结束：`末态 | 时间没锚点，切点乱跑 |
| **声音** | **独立成轨**：起—止秒 · 现场／画外 · 说话人 · 台词 | 台词塞进镜头描述 → 静默占 67%（实测） |
| **环境声／限制** | 音效 + 本组禁令 | 模型自行加 BGM、加字幕 |
| **结束** | 末态（人 · 物 · 位置） | 下一组接不上（`GRP-04`） |

## 模板

```text
9:16竖屏，{质感}，{光线}；{地点}，{时间}；{N}镜，生成{X}秒。
参考：{资产名}<Picture {n}>.png（{一行外观锚点}）、…、{场景}<Picture {n}>.png（{固定结构}）。
起始：接上组末态——{只写状态：谁在哪、面朝哪、手里有什么}。{不在本镜画面内的人写「（不在镜1 画面内）」}。机位{同侧轴/机位不越轴}。
镜1｜{起}—{止}s｜{景别}，{机位}：{可见动作序列}。结束：{末态}
镜2｜{起}—{止}s｜{景别}，{机位}：{可见动作序列}。结束：{末态}
声音｜{起}—{止}s｜现场｜{说话人}（**看向{对象}**，{语气}）："{原文一字不改}"
声音｜{起}—{止}s｜画外｜{说话人}（**看向{对象}**，{语气}）："{原文一字不改}"
环境声/限制：{音效}；无配乐；{本组禁令}。
结束：{人 · 物 · 位置 · 手在干什么}。
```

## 硬约束（脚本可阻断）

| ID | 约束 |
|---|---|
| `GRP-01` | **「参考」必须覆盖本组所有出场的人与物**——起始、结束、每一镜里出现的人都要在清单里 |
| `GRP-02` | **资产名必须带状态**：`林秀兰围裙` 不是 `林秀兰`（她这场穿着围裙）。别名表见 [space.md](space.md) §4 |
| `GRP-03` | **不使用首帧／尾帧**——本平台不支持 |
| `TIM-06` | 镜数＝声明；时间戳首尾相接；**总长＝声明秒数**（`--` 不给空档、不给重叠） |
| `AUD-04` | 声音轨的说话人必须在「参考」清单里 |
| `DIA-16` | **每句台词必须写「看向〈对象〉」**——否则对着空气说 |
| `DIA-17` | **说话人切换处必须留 ≥0.5s 空档**（含跨组）——那 0.5 秒就是**反应拍** |
| `CAM-04` | 正文不得出现焦距（`\d+mm`） |

## 一张资产图可能有多个部件（`GRP-05`）

**锚点要写全，不能只写主件。**

> 实例：`茉莉花香皂.png` 里同时有
> **①皂体**（椭圆白皂，正面压印"HQY"与椭圆线条，约 8.0×5.2cm、厚 2.5cm）
> 与 **②彩盒**（白底、金发女子侧脸＋菊花图案＋"HQY 茉莉花香皂"，约 9.5×5.8×3.0cm）。
> 只写"椭圆白色香皂" → **彩盒没有出处**，模型只能自己编，或者干脆不出现。

**而且必须分清两个"盒"**：

| 名词 | 在哪 | 怎么写 |
|---|---|---|
| **彩盒** | **在资产图里** | 引 `<Picture n>`，锚点里写清 |
| **快递盒** | **不在资产图里** | 按"普通牛皮纸色纸箱、胶带封口"**文字描述**，不引素材编号 |

**两者是不同的东西**——混成一个，模型就会拿彩盒当初流纸箱。

## 反应拍：听到 → 看向 → 才开口（`DIA-17`）

**台词时间戳首尾相接 = 抢话。** 说话人切换处留出的空档，**画面就是在做反应**。

```text
✗ 声音｜0—2.5s｜现场｜妈妈（看向晓雯）："{妈妈的话}"
  声音｜2.5—6s ｜现场｜晓雯（看向妈妈）："{晓雯的话}"        ← 空档 0.00s，抢话
✓ 声音｜0—2.5s｜现场｜妈妈（看向晓雯）："{妈妈的话}"
  声音｜3.2—7s ｜现场｜晓雯（看向志远，再转向妈妈）："{晓雯的话}"  ← 空档 0.70s
```

**配合画面写可见的四拍**：

```text
镜2｜2.5—3.2s｜近景双人（晓雯与志远同框）：妈妈话音落下 → 晓雯先是一怔
     → 转头看向志远 → 两人对视约半秒
镜3｜3.2—7s｜近景，机位偏晓雯：她才转回妈妈，开口
```

**两条注意**：

- **「对视」必须双人同框**（`SHT-07`）。单人近景拍不到对视。
- **这是 `SHT-06`（默认已经在进行中）的例外**：镜头**从"上一句说完"起算**，不是从"她开口"起算。
  反应拍是**表演**，不是"先做动作再开口"那种拖（见 [dialogue.md](dialogue.md) §7 的两类分法）。

## 只提示（不阻断）

| ID | 检查 |
|---|---|
| `SHT-07` | 写了「对视」的镜，景别不是双人——单人镜拍不到 |
| `SHT-08` | 镜1 没写明画面主体——`起始` 段会被当成镜1 画面 |
| `GRP-04` | 上一组「结束」的人与本组「起始」的人不相交——状态断链 |

## 与其他钟点的关系

- **时长算式**（[timing.md](timing.md) §5）：**降为校验**。主写法是时间戳；算式用来事后核对"这些字念得完吗"。
- **出声慢／静默多**：先查 `DIA-17`（有没有留反应拍）和 [troubleshooting.md](troubleshooting.md) §15。
