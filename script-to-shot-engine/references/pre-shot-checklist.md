# 分镜前信息收集模板

> 新对话收到剧本后，先按本模板逐项问清，**问齐了再开工**；拿不准的当场问，不猜。
> 核心：**场景与角色资产图必须先要到，拿到图才开始分镜**。

---

## ① 基础参数（不问会出大错）

| 项 | 示例 | 为什么重要 |
|---|---|---|
| 画幅 | 9:16 竖屏 / 16:9 横屏 | 景别、构图、人物占比全不一样 |
| 总时长目标 | 约 3 分钟 / 5 分钟 / 不限按剧情走 | 决定 Clip 数量和节奏密度 |
| 目标模型 | **Wan 3.0（通义万相 3.0）** | 提示词写法与单段时长上限（6—15 秒） |
| 视觉风格 | 真人写实 / 电影感 / 带货短视频感 / 其他 | 决定风格锁定词 |

---

## ② 人物表（每个主要角色一行）

| 项 | 示例（林秀兰） | 说明 |
|---|---|---|
| 姓名 + 年龄 | 林秀兰，68 岁 | 决定声音的年龄感（**外观由参考图锁，不写**） |
| 性格关键词 | 倔、善良、讲诚信 | 决定情绪走向 |
| 语速基准 | 标准 4 字/秒（含表演余量） | **只算时长，不是演出指令**（`DIA-15`）；节奏写在每句台词的「台词节奏」格里 |
| 外观 + 标志道具 | 旧棉袄、揉腰、冻僵手指 | 决定镜头怎么拍 |
| 有没有角色参考图 | 有 / 没有 | 有图按图写，没图先问 |

---

## ③ 场景与资产图（先要到才开工）

| 项 | 示例 | 说明 |
|---|---|---|
| 几个场景 | 早市路口 / 会议室 / 办公室 | 决定分场和 Clip 划分 |
| 每个场景固定结构 | 山货摊在左、轿车在右、门在哪 | 决定锚点清单与轴线 |
| 关键道具/植入物 | 德绒护腰、一万块钱、一百元 | 决定物理锁死和特写 |
| **有没有场景图、道具图** | 有 / 没有 | **没图先问，拿到才开工** |

---

## ④ 剧本本身的补充

| 项 | 说明 |
|---|---|
| 情绪/语速在台词旁标了吗 | 没标的话逐句问，不自己编情绪 |
| 关键爽点/转折在哪几场 | 决定哪里慢镜、哪里快剪 |
| 特殊镜头要求 | 一镜到底、慢镜、闪回、产品特写 |
| 字幕/转场要求 | 字幕卡、黑屏、渐隐 |

---

## ⑤ 我拿不定的，当场问你

不猜，直接问，比如：

- 这场争吵是谁占上风？
- 这个表情是委屈、倔强，还是认命？
- 两人距离该多远（一臂 / 一步 / 隔摊）？
- 这个道具是左手拿还是右手拿？
- 这句台词是着急、平静，还是哽咽？

---

## 开工确认

问完以上五项，确认拿到：
1. ✅ 基础参数（画幅、时长、模型、风格）
2. ✅ 人物表（年龄、性格、语速、外观）
3. ✅ 场景图 + 角色图 + 道具图
4. ✅ 剧本补充（情绪标注、爽点、特殊要求）

**齐了才开始分镜；缺哪项问哪项，不编。**
