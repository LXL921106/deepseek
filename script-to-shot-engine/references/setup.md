# §3 全局设置（一次定好，中途不许改）

**统一强制约束（每单元开头重复）**：9:16 竖屏原生不裁切｜严禁 BGM｜严禁字幕｜严禁穿模｜严禁乱码｜有台词时口齿清晰｜**同一角色同一帧只出现一次**。

**画质质感（全片统一）**：原始质感，纪录片风格，粗糙胶片颗粒，随机颗粒度，低饱和度，低对比，柔和的高光弥散，降噪，低锐化，场景微量模糊，笼上一层灰色滤镜。
**光影层次**：低反差、高灰阶过渡，明暗交界线柔和，无死黑/过曝。
**皮肤质感**：完全保留皮肤纹理与瑕疵，无磨皮。

**英文摄影机头（每单元开头一次，仅色温随单元变）**
```
ARRI ALEXA 35, f/2.8, shallow depth of field, natural light, {色温}K, photorealistic, high detail texture, film grain, professional color grading. 9:16竖屏。
```

**光线三层叠加**：① 胶片层＝上面质感统一垫底；② 戏剧层＝按色调方案给每镜定光位/光比/色温；③ 自然光优先＝默认自然光，室内/黑夜/特殊环境才用人造光并写唯一光源位置·方向·色温·补光。跨时间叙事须标：早晨→正午→黄昏→夜晚。

**全局主色调方案（先出总表，全片共用）**：`情绪节点 → 色调 → 高光色值/阴影色值 → 色温 → 说明`。禁止只写"暖色/冷色"；一个场景只用一套方案。备选：青橙（冷峻/动作）、蓝紫（科幻/悬疑/夜）、暖棕（温情/回忆）、墨绿金（古装/史诗）、高反差黑白（压抑/刑侦）。

**角色与场景标记（只绑参考图 + 声线，不写外观）**
- 每个角色绑一张参考图：`@周大河<Picture 1>（声线：沙哑中年男音）`
- 每单元开头精简标记：`人物：@周大河<Picture 1>（声线：沙哑中年男音）、@许梅<Picture 2>（声线：温和中年女音）｜场景：周家早点铺门口<Picture 3>·清晨｜道具：热粥桶`
- **人物外观由 `<Picture N>` 锁定，不写年龄、体态、发型、服装、品牌名**——写了反而和参考图打架。

**全局角色-声线绑定（同一角色全片不变）**

| 角色 | 声线 |
|---|---|
| @文文 | 尖利急躁青年女音，尾音上扬 |
| @李大牛 | 犹疑拘谨中年男音，句尾下沉 |
| @母亲 | 朴实温和老年女音，气声足 |

> **声线只写音色，不写语速**（`DIA-15`）。
> 语速写在**每一句台词**的 `台词节奏` 格里（默认"正常"）。写在这一行会**全片套用同一个速度**——
> 实测「语速慢」一旦落在角色基线上，整部戏都拖，而且**改算式档位救不回来**（模型看不见数字）。

**停顿标记（写在台词内，不念出）**

> 台词内 `|N|` 表示此处停顿 N 秒——**它不是台词，不念出、不做口型、不计入字数**。

**停顿必须写出来**：每个逗号、句号处的停顿都要写成行内 `|N|`（`DIA-13`）。**不要依赖"默认按标点停"**——实测不写的时候，模型会在句读处自行停 **1.4—2.5 秒**（正常人 0.2—0.3），把 43% 的时长吃掉。
