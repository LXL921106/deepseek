# 镜与声音两行 · 输出 · 台词回勾表（§9 §10 §11）

# §9 镜与声音两行怎么写

**组格式没有"每镜二十个字段"。** 每一镜只有 **两行**（外加 `结束：`），逐镜字段定义见
[group-format.md](group-format.md) —— **本节不重述模板，只讲这两行容易写错的地方。**

```text
镜N｜{起}—{止}s｜{景别}，{机位}：{可见动作序列}。结束：{末态}
声音｜{起}—{止}s｜{现场/画外}｜{说话人}（看向{对象}，{语气}）："{原文一字不改}"
```

## 镜N 那一行

- **景别 + 机位**：只写景别，**不写焦距**（`CAM-04`：写了 mm 会被执行成中远景）。
- **可见动作序列**：看图说话，**只写看得见的身体与脸**。✓"眉头皱起，下巴抬高，后退半步" ✗"他很感动" ✗"他想了想"。
- **`起始` 段只写状态，不写画面**——它的描述会被模型当成镜1 的画面（实测：写了"志远抱衣服"，镜1 就拍了他 2.33 秒）。不在本镜画面里的人，写「（不在镜1 画面内）」。
- **切镜要双对比**（`SHT-05`）：每次切镜**同时**改景别和机位性格。✗ `中景手持→近景手持` ✓ `中景手持→特写固定`。
- **同人声明**（`CNT-08`）：**越肩镜/带前景人物的镜必写**——前景的〈角色名〉与画面里的〈角色名〉是同一个人，本镜〈角色名〉只出现这一次。其余不写。
- **本镜禁止**：只写本镜专属的负向项（如：粥桶穿模、出现第二个穿外卖服的人）。**不要写通用禁令**——通用禁令在组头的统一约束里。

## 声音那一行

- **原文一字不改**。指示写在括号里，**不念出来**。
- **必写「看向〈对象〉」**（`DIA-16`）——否则对着空气说。
- **说话人切换处留 ≥0.5s 空档**（`DIA-17`）：那 0.5 秒就是**反应拍**。见 [dialogue.md](dialogue.md) §7。
- **停顿必须写成 `|N|` 行内标记**，落在台词里：`"哎，|0.3|你们俩，|0.3|什么时候结婚呀？"`
  ✗ 只写描述句「逗号后 0.3 秒」——实测模型不执行，该停 0.3 秒的地方停了 **1.40 秒**，听起来像结巴。
- **节奏默认「正常」**。**不要默认写"缓慢"**；**永远不要写"字字清晰"**（会变成一字一顿）。只有剧本明确要求（哽咽、虚弱、喃喃）才写慢，并给出场景理由。
- **画外音**写 `声音｜…｜画外｜…`，并在镜里点明**嘴唇不动、不张嘴**。

## 子镜

**机位与主体不变、只是动作分步** → 不必拆镜，写在同一个「镜N」的动作序列里。
**换机位、换主体、插反应镜头** → **升为独立镜号**，并给它自己的时间戳。

## 前后景与虚实写在动作描述里，不单列

景别已决定虚实，不必再抄一遍。
✗ 分两栏：`动作：周有福蹲在门槛前擦粥。` + `景深层次：前景粥迹（焦内），背景铺门（虚化）`
✓ 一句说完：`周有福蹲在门槛前擦粥，前景是摊开的粥迹，背后的铺门虚化成一片暖灰。`

## 手机屏 / 电脑屏 / 电视屏怎么拍（这类镜头最容易翻车）

- **屏内不许生成可读文字**。要"直播弹幕""评论区"的观感，只做**文字感示意**：滚动条、评论气泡、头像圆点、点赞心形飘动、进度条——**不生成任何字形**。
- 真实评论文字**留给后期合成**（剪映贴字），模型只负责"这是个热闹的直播间"的视觉印象。
- **机位越肩拍屏**：从人物侧后方、越过肩膀拍屏幕，屏里同时有人物的脸与屏内界面。这样既不跳出本组既定视角，又能一镜交代"她在直播"。
- 屏内必须看得见**人物自己的脸**（前置摄像头画面）+ **示意性弹幕区**，这才是这一镜的视觉重点。
- **本镜禁止里必须写死**：`屏幕不出现可读字形/乱码/品牌 logo`。
单镜无子镜时，`声画同步` 写一行：`单镜连续动作 {X}s`。
**子镜**：机位与主体不变、仅动作分步 → 写 `镜头1/镜头2` 并各标秒数；**换机位、换主体、插反应镜头 → 升为独立镜号**。

**前后景与虚实写在画面描述里，不单列**。景别已决定虚实，不必再抄一遍。
✗ 分两栏写：`画面描述：周有福蹲在门槛前擦粥。` + `景深层次：前景粥迹（焦内），背景铺门（虚化）`
✓ 一句说完：`画面描述：周有福蹲在门槛前擦粥，前景是摊开的粥迹，背后的铺门虚化成一片暖灰。`

**手机屏 / 电脑屏 / 电视屏怎么拍**（这类镜头最容易翻车）
- **屏内不许生成可读文字**。要"直播弹幕""评论区"的观感，只做**文字感示意**：滚动条、评论气泡、头像圆点、点赞心形飘动、进度条——**不生成任何字形**。
- 真实评论文字**留给后期合成**（剪映贴字），模型只负责"这是个热闹的直播间"的视觉印象。
- **机位越肩拍屏**：从人物侧后方、越过肩膀拍屏幕，屏里同时有人物的脸与屏内界面。这样既不跳出本组既定视角，又能一镜交代"她在直播"。

# §10 输出

**首次输出**：**本轮的全部组**（每个都带 `组N｜原文范围：…` 标题行）。

**每组按 [group-format.md](group-format.md) 的七段模板写**（头 / 参考 / 起始 / 镜N / 声音 / 环境声·限制 / 结束）。
**`组N` 必须单独一行打头**——缺了门禁 `FMT-03` 会红。
**末尾一行续接**：`已完成组 X—Y｜下一轮从组 Z 起｜回复"继续"`。

**平台时长按组的声明秒数设置**（6—15 秒）。

# §11 台词逐句回勾表（本项目增量）

凡剧本含台词，每个交付批次都必须输出这张表。**它是对用户的可见承诺，不是内部草稿。**

| 剧本位置 | 说话人 | 台词原句（完整字符串） | 落点 | 状态 |
|---|---|---|---|---|
| SC001 · 第12句 | 苏晓雯 | 妈，您在电话里说有事要跟我们说，我们吓得赶紧请假回来的。 | 组11 镜4 → 组12 镜1（跨组接续） | ✅ |

规则：
- **一行一句，按剧本顺序排**，不许按组顺序重排。
- **「台词原句」必须写完整字符串**，包括逗号／破折号后面的半句。**以逗号或破折号结尾的句子不许只填前半句。**
- **「落点」为空即为漏句**，该批次不得交付。
- 尚未生成的段落用 `⬜` 标记并填「—」，**不许省略不写**。
- 以逗号／破折号结尾的句子，落点写清接续位置（同组写 `组11 镜4 → 镜5`；跨组写 `… → 组12 镜1（跨组接续）`）。
- 剧本设计为被打断的句子，「状态」列写 `⚠️ 话被打断`。
- 表内台词**必须与正文逐字一致**（`|N|` 标记不算）；对不上以剧本为准改正文。
