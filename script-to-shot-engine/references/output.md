# 单镜头模板 · 输出 · 台词回勾表（§9 §10 §11）

# §9 单镜头模板

```
### 镜头 XX | {景别} | {运镜方式} | {机位/视角}
**时长计算**：{N}字÷{语速}={X}s + 缓冲情绪{0-2}s = {总}s   （动作镜写：动作步长 {X}s + 情绪{Y}s）
**场景**：{场景名}（锚点：{锚点1}位于画{左/中/右}，{锚点2}位于画{…}）
**出场人物**：{单人镜只写一人；无则"无"}
**道具**：{本镜要用到的物件；无则"无"}

**空间坐标**：{谁在画中/画左/画右，与锚点关系}
**同人声明**：{越肩镜/带前景人物的镜必写：前景的〈角色名〉与画面里的〈角色名〉是同一个人，本镜〈角色名〉只出现这一次。其余写"无"}
**画面描述**：{看图说话 3-5 句，引锚点；含光线方向、背景锚点、关键细节；**前后景与虚实直接写在句子里**；无服装、无品牌名}
**光影**：{**只写与单元头"光线"不同的地方**：光位偏移、明暗反转、光源切换、光比变化。没变化就写"同上"}
**色调**：{方案名}，高光{色值}，阴影{色值}，色温{数值}K。
**运镜**：{单个运镜+细节}
**构图**：{9:16 构图说明}
**声画同步**：
- 镜头1（{景别}，{X}秒）：{分步动作}
- 镜头2（{景别}，{X}秒）：{分步动作}
**台词同期**：{有台词时**必填**：台词与〈本镜哪一个动作〉同时开始，**不先〈动作〉再开口**——本镜第一个声音就是说话；无台词写"无"}
**台词**：{按 §7.1 句式}：「{台词原句，**停顿写成 `|N|` 行内标记**，如 `哎，|0.3|你们俩，|0.3|什么时候结婚呀？`}」
**停顿**：{有台词时**必填，且必须落在台词里当标记**——**不要只写「逗号后 0.3 秒」这种描述句**：实测那种写法模型不执行，该停 0.3 秒的地方停了 **1.40 秒**，听起来像结巴。把每个停顿写成台词里的 `|0.3|`／`|0.5|`，就钉在那个字后面。}
**台词节奏**：{给模型的演出指令，**默认写「正常」**。**不要默认写"缓慢"**——它会让整句拖；**永远不要写"字字清晰"**——那会变成一字一顿。只有剧本明确要求（哽咽、虚弱、喃喃）才写慢，并且必须同时给出对应场景理由}
**人声**：{台词外的表演性人声；无则"无"}
**音效**：{环境音+动作音；安静则"环境底噪"}
**人物情绪**：{2-4 字，如：专注、熟练}
**本镜禁止**：{本镜专属负向项，如：粥桶穿模，倒油动作僵硬，出现第二个穿外卖服的人}
**强制约束**：同统一约束。
```

单镜无子镜时，`声画同步` 写一行：`单镜连续动作 {X}s`。
**子镜**：机位与主体不变、仅动作分步 → 写 `镜头1/镜头2` 并各标秒数；**换机位、换主体、插反应镜头 → 升为独立镜号**。

**前后景与虚实写在画面描述里，不单列**。景别已决定虚实，不必再抄一遍。
✗ 分两栏写：`画面描述：周有福蹲在门槛前擦粥。` + `景深层次：前景粥迹（焦内），背景铺门（虚化）`
✓ 一句说完：`画面描述：周有福蹲在门槛前擦粥，前景是摊开的粥迹，背后的铺门虚化成一片暖灰。`

**手机屏 / 电脑屏 / 电视屏怎么拍**（这类镜头最容易翻车）
- **屏内不许生成可读文字**。要"直播弹幕""评论区"的观感，只做**文字感示意**：滚动条、评论气泡、头像圆点、点赞心形飘动、进度条——**不生成任何字形**。
- 真实评论文字**留给后期合成**（剪映贴字），模型只负责"这是个热闹的直播间"的视觉印象。
- **机位越肩拍屏**：从人物侧后方、越过肩膀拍屏幕，屏里同时有人物的脸与屏内界面。这样既不跳出单元既定视角，又能一镜交代"她在直播"。
- 屏内必须看得见**人物自己的脸**（前置摄像头画面）+ **示意性弹幕区**，这才是这一镜的视觉重点。
- 本镜禁止里必须写死：`屏幕不出现可读字形/乱码/品牌 logo`。

# §10 输出

**首次输出**：全局设置 → 场景锚点 → 角色与声线标记 → **台词逐句回勾表** → **本轮的全部单元**（每个都带 `单元 N` 标题行）。
**每单元开头**：**`单元 N` 单独一行打头（必写，缺了门禁 `FMT-03` 会红）** → 英文摄影机头 → 一句话场景 → **共N镜共X秒** → 人物/场景/道具标记 → 统一强制约束 → 光线 → 空间调度 → 色调 → 承接上一单元。
**每单元结尾**：物理 → SFX → 禁止 → **总计X秒/N镜/9:16**。
**末尾一行续接**：`已完成单元 X—Y｜下一轮从镜头 Z 起｜回复"继续"`。

**平台时长按「总计X秒」设置**（6—15 秒）。

# §11 台词逐句回勾表（本项目增量）

凡剧本含台词，每个交付批次都必须输出这张表。**它是对用户的可见承诺，不是内部草稿。**

| 剧本位置 | 说话人 | 台词原句（完整字符串） | 落点 | 状态 |
|---|---|---|---|---|
| SC001 · 第12句 | 苏晓雯 | 妈，您在电话里说有事要跟我们说，我们吓得赶紧请假回来的。 | 单元11 镜头4 → 单元12 镜头1（跨单元接续） | ✅ |

规则：
- **一行一句，按剧本顺序排**，不许按单元顺序重排。
- **「台词原句」必须写完整字符串**，包括逗号／破折号后面的半句。**以逗号或破折号结尾的句子不许只填前半句。**
- **「落点」为空即为漏句**，该批次不得交付。
- 尚未生成的段落用 `⬜` 标记并填「—」，**不许省略不写**。
- 以逗号／破折号结尾的句子，落点写清接续位置（同单元写 `单元11 镜头4 → 镜头5`；跨单元写 `… → 单元12 镜头1（跨单元接续）`）。
- 剧本设计为被打断的句子，「状态」列写 `⚠️ 话被打断`。
- 表内台词**必须与正文逐字一致**（`|N|` 标记不算）；对不上以剧本为准改正文。
