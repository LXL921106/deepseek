# §7 台词与声音

## 6.1 台词句式

**恒定项**：`原文一字不改`。**`看向某某` 仅在有对话对象时写。**

**给模型的节奏指令只有一处**：`（{台词节奏}）`，**默认写「正常」**。

- **不要默认写"缓慢"**——它会让整句拖。
- **永远不要写"字字清晰"**——那会变成一字一顿。
  > 实测（单元 11）：4 句台词写了 4 遍「字字清晰」，成片里每 2—7 个字就断一次，逗号处停 **1.40 秒**（正常人 0.2—0.3 秒）。**听起来像结巴，不像正常人在说话。**
- 只有剧本明确要求（哽咽、虚弱、喃喃、气声）才写慢，并同时给出场景理由。

| 场景 | 句式 |
|---|---|
| 有对话对象 | `台词：{说话人}看向{对象}（{台词节奏}）：「原文一字不改」` |
| 无对话对象（自语/喊话/对空/对背影） | `台词：{说话人}（{台词节奏}）：「原文一字不改」` |
| 画外音 OS | `台词：【画外音】{说话人}（{台词节奏}）：「原文一字不改」 ——嘴唇不动，不张嘴` |

语气贴合本镜内容（压着怒火的低吼、强撑镇定、哽咽着想笑、冷漠陈述）——**但语气不等于拖慢**。无台词写"无"。
**台词字数不单列**：字数只出现在「时长计算」的算式里（`14字÷4=…`），**不单独占一行**——镜头时长由表演决定，不是由字数决定。

**`「」`外是指示，`「」`内才是台词**：`（台词节奏）`、`看向某某` 属表演指示，**不念出来**。

### 停顿必须写成 `|N|` 行内标记（`DIA-13`）

```text
✗ 描述句：台词：林秀兰（语速缓慢，逗号后 0.3 秒）：「哎，你们俩，什么时候结婚呀？」
   → 实测：模型不执行这句描述。该停 0.3 秒的逗号处，它停了 1.40 秒。

✓ 行内标记：台词：林秀兰（正常）：「哎，|0.2|你们俩，|0.2|什么时候结婚呀？」
   → 钉在字上，它才照做。
```

**三档，从粗到细**：

1. **整句默认** → 不写任何停顿标记，模型按标点自行处理（**风险最高，实测会放大到 1.4 秒**）。
2. **逐处标出** → 每个逗号/句号后写 `|0.2|`／`|0.3|`。（**推荐**）
3. **精确到字** → `|N|` 标在任意两个字之间。

`|N|` 写在 `「」` 内，但**不是台词**——不念出、不做口型、不计入字数（见 §3 图例）。

### 示例

```text
台词：傅言深看向阿萍（正常）：「你现在瘦了，|0.3|也憔悴了。|0.5|阿萍，真认不出我了？」
```
（`|0.3|`、`|0.5|` 不计入字数。**台词字数不单列**——它只出现在「时长计算」的算式里。）

## 6.2 音频

**严禁 BGM**；安静就用环境底噪。只用**音效 SFX** 与**人声**，**分开标注不混写**。人声=台词外的喘息、抽泣、轻笑、叹气。SFX 在单元内统一收在末尾一行，逗号分隔。
