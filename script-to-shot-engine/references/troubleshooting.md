# 参数降级 · 故障排查（§14 §15）

# §14 参数降级（平台不支持时）

本渲染器默认平台支持多镜头、参考图与原生音频。**平台不支持时按下表降级，不要把不支持的参数硬写进提示词**。

| 能力 | 支持时 | 不支持时 |
|---|---|---|
| 时长设置 | 按 §5 算出的值（6—15 秒） | 按平台默认，并在提示词里写明「共N镜共X秒」 |
| 参考图 | 绑定为人物身份 | 退回文字外观设定（这时才写年龄、体态、发型） |
| 原生对白 / 声音 | 指定语言、说话人、声画同步 | 生成无声画面，后期配音拟音 |
| 视频编辑 | 「只改 X，保持 Y」 | 从原视频抽稳定首帧，改走图生视频 |

# §15 故障排查（结果不对时先查这张表）

| 现象 | 原因 | 修复 |
|---|---|---|
| **同一角色出现两次** | 越肩镜前景没声明"是同一个人"；或空间描述与分镜互相矛盾 | 加「同人声明」；删掉自相矛盾的方位句；写死"本镜〈角色名〉只出现一次" |
| **台词整体后移** | 中间插了无台词镜 | 实测每插一个无台词镜，后面台词推后 ≈ 该镜时长；把反应镜并进台词镜做画外音，或把台词镜紧邻 |
| **静默多、发声少** | 没把停顿写成 `|N|`，模型自行停 1.4—2.5 秒 | **每句台词的停顿都写成行内 `|N|`**（`DIA-13`） |
| **景别比写的松** | 写了焦距或"近景+慢推" | 删掉焦距；"慢推"限定为"在本景别内缓推" |
| **人物跨镜变脸** | 靠文字设定锁外观 | 改用 `<Picture N>` 锁；不要再写年龄/体态/发型/服装 |
| 动作过大 / 失控 | 只写「动起来」 | 指定动作部位与幅度；镜头仅推进 X%；背景人物保持静止 |
| 道具 / 商品变形 | 复杂运镜、特效、旋转同时发生 | 先固定正面只动摄影机；加锁定块；特效留到第二次迭代 |
| 动作像瞬移 | 只写开始与结果 | 补 2—3 个连续动作节点 + 环境反馈 |
| 左右位置反转 | 反打没写轴线与视线关系 | 声明「A 始终在 B 画面左侧，机位不越过连线」 |
| 口型错误 | 句子太长、多人同时说话、停顿不明确 | 缩短台词；一次一人说话；**写 `|N|` 停顿**；注明非说话者闭嘴 |
| 画面乱码文字 | 环境里有招牌 / 包装 / 屏幕 | 明确「所有招牌为空白或抽象图形」；准确文字留后期 |

## 重试模板（一次只改一个变量）

```text
重试上一版本，仅修复：{一个问题}。
必须保持：{人物/商品身份、场景、构图、动作、时长中的不变项}。
具体调整：{可测量的幅度或单一镜头修改}。
不要新增人物、道具、对白、转场或特效。
```

- 迭代顺序：基础版（一个主体 + 一个动作 + 一个运镜）→ 固定满意的首帧 / 角色 → 只加环境反馈或声音 → 最后才加转场、多镜头、特效。
- 每次只改一个变量并记录，失败才能回退。
