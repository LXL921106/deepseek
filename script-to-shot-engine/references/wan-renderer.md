# Wan 3.0 渲染模板（万相3.0 / 通义万相3.0分支）

> 本文件是「剧本转分镜」技能的 Wan 3.0 渲染分支。**目标模型为万相 3.0（Wan 3.0）时启用本渲染器**；目标模型为 Seedance 2.x 时仍走 `seedance-prompt-renderer.md`。启用后替代 Seedance 渲染器的正文结构与输出格式。
>
> 当前面向**对话 / 情感短剧（对峙文戏）**；动作打斗戏暂不使用本渲染器。
>
> 依据：阿里云《万相3.0视频生成Prompt指南》官方公式 + 本技能自有资产引用方式（@名字）+ 用户实测反馈。

## 核心公式

```text
提示词 = [参考素材：@名字引用]
       + [分镜N（起-止秒）：主体 + 场景 + 运动 + 美学控制 + 台词写进对应说话人镜头 + 谁开口口型同步]
       + [音效 / 无BGM（后期配音）]
       + [风格/情绪：画风 + 色调 + 情绪]
       + [负向清单]
```

台词直接写进说话人分镜里，不再单列台词块；分镜列表本身就是「说话人 → 听方反应 → 双人同框」交替的时间轴，从结构上避免"一张嘴讲 15 秒"。

## 与 Seedance 渲染器的差异

| Seedance 渲染器 | Wan 3.0 渲染器 | 说明 |
|---|---|---|
| 六槽位风格锁定（媒介/渲染/角色/运动/材质/光影） | 风格/情绪三件套：画风 + 色调 + 情绪 | 官方格式，见「风格/情绪」节 |
| @资产名[参考图标签] | @名字（保留本技能资产引用方式） | 见「参考素材」节 |
| 全局角色声线绑定（每Clip重申） | 音色写进台词描述（纯文字） | 有音色参考音频时写 `音色参考 音频N` |
| 皮肤质感固定句 | 不写；如需控制写进分镜主体或负向清单 | 删固定句 |
| 台词写在镜头内（镜头N + 光圈 + 焦段） | 台词写进分镜内（分镜N + 焦段，全中文） | 不用独立台词块，见「台词与分镜」节 |
| 特殊风格化声明（回忆/梦境） | 直接写进色调：偏暗偏黄、胶片颗粒 | 无独立声明块 |
| 视听术语 中文（English） | 全中文 | Wan 官方示例全中文 |
| 约束（结尾集中写） | 负向清单（结尾集中写） | 语义相同，见「负向清单」节 |
| 镜头N（起-止秒） | 分镜N（起-止秒） | 时间戳格式相同 |

## 参考素材（@名字引用）

- 用户上传前把图片文件名统一为角色/场景/道具名（如 `林秀兰.png`、`林秀兰围裙.png`、`客厅.png`、`山药棒.png`），上传后模型自动识别，提示词用 `@名字` 引用。
- 参考素材块列出本 Clip 全部 @引用 + 一句话用途，人物图锁外观不锁场景，场景图锁环境不含人物：

```text
参考素材：@林秀兰（银发短卷、酒红开衫，仅锁外观）；@沈志远（深色西装，仅锁外观）；@客厅（北欧风客餐一体空场景，锁环境不含人物）。
```

- 人物变装是独立参考图：@林秀兰 与 @林秀兰围裙 是两张图，按 Clip 实际着装引用。
- 正文（台词、分镜）**一律用人物名字**，不用 @、不写图N；每句台词、每个分镜都带全人物名（含变装名），禁止用"她/他/妈妈"等代词指代说话人，避免多角色混淆。
- 贯穿剧情的关键道具（防走失卡、日记本、产品等）有专属参考图，同样 @引用；道具参考图上的文字本身是空白/模糊的。

## 台词与分镜（台词写进分镜内）

说话人分镜里直接写台词原句，格式：`人物名（语速/情绪）："台词原句"，口型同步`。不再单列台词块。

```text
分镜2（1.5-4秒）：@客厅，林秀兰抬头面向沈志远，右手捏着一根菜，表情平静带疑惑，开口说（语速缓慢，温和沙哑）："你们回来干什么？"，口型同步，85mm中近景，浅景深背景半虚化。
分镜3（4-5.5秒）：@客厅，沈志远皱眉，双手微摊，面向林秀兰，无台词，85mm中近景（听方反应镜头）。
```

规则：
- 每句必带说话人全名（变装写"林秀兰围裙"）；一句完整台词不跨镜、不跨 Clip。
- 语速写进台词描述：语速缓慢/语速急促/语速平稳；基线参考：老人≈3字/秒、普通成年人≈4、年轻人快嘴≈5-5.5；情绪激烈在自己基线上加快，沉静/哽咽放慢，不跨到别人档位。
- 音色用文字描述（温和沙哑中老年女声、浑厚青年男声等）；有音色参考音频时追加 `音色参考 音频N`。
- OS念白/旁白用官方格式：`画外音（林秀兰，语速缓慢）："……"`。
- 方言对白保留原文，不改写为书面语。
- 听方反应镜头不重复播放台词，只写反应本身（表情、视线、微动作）。
- 2 秒以内镜头台词 ≤6 字；字数超了就拆镜或延长，不删减台词。

## 分镜节奏与镜头配额（核心：说话与反应交替）

### 镜头总数（15秒对话戏）

5—8 个镜头，按情绪节奏分配，不为凑数加镜、不为凑数切分台词。

### 强制构成（每 15 秒）

| 镜头类型 | 数量 | 作用 |
|---|---|---|
| 空间建立 / 双人同框 | ≥1 | 交代谁站谁坐、距离、空间权力；**穿插在中间，不是只在开头** |
| 说话人镜头 | 拍正在说话的人 | 一句台词一个镜头，人物开口说话、台词完整 | 
| 听方反应镜头 | 按情绪和戏自然安排 | 听者的表情、微动作、视线变化；不做数量下限 |
| 微动作特写 | 1—2 | 手 / 道具 / 指节 / 烟 / 扇 |
| 局势变化 / 收尾 | 1 | 关系改变、座位 / 持物变化 |

### 交替硬规则（避免同一人霸屏）

1. **同一角色连续出镜不超过 2 个镜头**（无论说话还是反应）。
2. **说话人镜头之后接「听方反应」「双人同框」或「微动作」，不直接接下一个说话人镜头**——尤其禁止同一个人连续说两句中间不插反应。
3. **反应镜头不连续超过 2 个**；同一角色的同一反应不重复拍。
4. **每 15 秒至少 1 个双人/多人同框镜头**，建议放在第 3—6 镜之间，交代空间关系，避免全程单人近景。
5. 多人戏每个镜头写明焦点人物外，用一句交代背景人物状态（「其余人保持原位静止」或具体微动作，如"七叔摇扇未停"）。

### 镜头时长（不定死，按情绪节奏）

- 冲突/争吵快剪 1.5—2 秒/镜；情绪戏/凝滞 3—4 秒慢镜；过渡镜头 1 秒带过。
- 说话人镜头时长 ≥ 台词时长 + 0.3—1 秒表演缓冲；不按"字数÷语速"硬算。
- 开场 30 秒内进冲突；不为凑时长加镜头。

### 物理锁死五项（每个分镜写一次，防跨镜头/跨Clip漂移）

| 项 | 写法 | 示例 |
|---|---|---|
| 持握手 | 哪只手拿什么，不换手 | "林秀兰右手拿菜" |
| 朝向 | 面向谁/哪，不翻转 | "志远面向门口方向" |
| 距离 | 两人相距多远 | "两人相距约一臂" |
| 接触点 | 手碰哪/物递到哪只手 | "林秀兰右手把鞋带绕两圈" |
| 步速 | 老人/伤者写慢 | "林秀兰步速慢" |

跨 Clip 用"承接上一段"起句，保持五项连续。

### 竖屏对话/情感戏默认景别（9:16）

对话戏与情感戏默认中近景（MCU），参数写死：

- 焦段约 85mm（80-100mm）；取景自头顶至桌面入画。
- 人物居中偏下，头顶留白约 1/10（不顶满）；人物约占画面宽 2/3。
- 前景道具（餐桌、手持物）入画画面下 1/4；背景半虚化、保留场景辨识度。
- 双人对话优先过肩（over-the-shoulder），或让对方肩部/手臂入画边缘，不必完全同框。
- 反应镜头、双人同框、环境镜头不受此默认景别约束（双人同框用 35—50mm 中景/全景）。

## 画面内文字

- 便利贴、日记本、防走失卡等画面内文字：模型生成中文手写字易乱码，统一处理为**能看出字块轮廓、不可读**（字小而密、虚焦），OS/画外音念出内容。
- 道具参考图上的字本身是空白/模糊的，不要求模型生成清晰文字。
- 文字类特写如需清晰，走图生视频（道具参考图带字）或后期合成。

## 音效 / BGM

- 环境音、动作音效按场景写进音效块或分镜描述（官方会自动按画面材质匹配音效）。
- **BGM 定死：全程无背景音乐**（本项目台词走后期配音，成片再配乐），写 `无背景音乐` 或 `No background music.`；每 Clip 负向清单固定带此项。

## 风格 / 情绪（官方三件套）

官方格式：画风 + 色调 + 情绪关键词，可放提示词开头或结尾。

```text
风格：电影摄影，实拍，真人质感，自然光生活片。
色调：日间柔光，暖色调，明亮通透。
情绪：温馨日常（本段）/ 压抑紧张（冲突段）/ 悲伤释然（结尾段）。
```

- 画风：媒介与质感（电影摄影/实拍/动画/插画…）。
- 色调：光源、光线环境、色彩倾向（柔光/暖调/高对比/胶片颗粒…）。
- 情绪：官方词库示例——悲壮孤峙、轻快治愈、压抑紧张、松弛自信、神秘魔幻；情感戏可按段落写具体情绪。
- 回忆/梦境段：色调叠加偏暗偏黄、胶片颗粒、暖一度，与现在时空区分。
- 人物表演情绪（克制/焦急/哽咽等）写进分镜描述，不堆在风格块。

## 负向清单

结尾集中写一次，每 Clip 固定项 + 本 Clip 相关项：

```text
负向清单：无字幕、无水印、全程无背景音乐；不要人脸变形/换脸/多余手指/肢体扭曲/穿模；不要人物位置跳变/服装变化；不要轴线错乱；不要与场景描述不符的多余路人。
```

- 固定项：无字幕、无水印、全程无背景音乐、人脸变形/换脸/多余手指/肢体扭曲/穿模、人物位置跳变/服装变化、轴线错乱、与场景描述不符的多余路人。
- 路人密度按剧情写进分镜场景描述（人潮涌动/人流渐稀/无人），负向只防"与描述不符的多余路人"。
- 画面内文字不写入负向清单（由分镜正向写"字迹模糊不可读"控制）。

## 生成前提醒

- 最多三条；没有明显问题时写"未发现明显资产冲突"。
- 参考素材若有新增道具图，提醒用户按 @文件名 上传。

## 最终检查（输出前内部核对）

- 目标模型确认为 Wan 3.0，未误用 Seedance 渲染器结构。
- 参考素材块列出本 Clip 全部 @引用且用途切清（外观/场景/道具不串位）。
- 台词写进说话人分镜内：每句带说话人全名 + 语速情绪 + 台词原句 + 口型同步；变装名写全；OS用画外音格式；方言保留原文。
- 台词不跨镜、不跨 Clip；听方反应镜头不重复播放台词。
- 交替规则：同一角色连续出镜 ≤2 镜；说话人镜头后接反应/双人同框/微动作；反应镜头不连续超 2 个；每 15 秒 ≥1 双人同框；听方反应按情绪和戏自然安排，不做数量下限。
- 分镜：每镜带起止秒、谁在哪做什么、面向、距离、持物、谁开口；无独立台词块残留。
- 镜头时长按情绪节奏（快剪1.5-2/情绪3-4/过渡1）；2秒内镜头台词≤6字。
- 物理锁死五项在每个分镜可查；跨Clip用"承接上一段"。
- 竖屏对话戏为85mm中近景参数（头顶留白1/10、人物占宽2/3、前景道具下1/4、背景半虚化）；双人同框用35-50mm中景/全景。
- 画面内文字写"字迹模糊不可读"；道具参考图文字空白/模糊。
- 风格/情绪为三件套（画风+色调+情绪）；回忆段色调含偏暗偏黄胶片颗粒。
- 负向清单含无字幕/水印/BGM定死；无"画面文字不清晰可读"项。
- 相邻分镜首尾相接、无重叠、最后分镜结束在Clip总时长。
