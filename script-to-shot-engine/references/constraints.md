# 硬约束 · 剧本不可改 · 参考素材引用（§1 §2 §13）

# §1 硬约束（已定死，**不要问用户**）

| 项目 | 固定为 |
|---|---|
| 画幅 | **9:16 竖屏** |
| 目标模型 | **Wan 3.0（通义万相 3.0）** |
| 视觉风格 | **真人写实** |
| 单次时长 | **6—15 秒**，由 §5.1 算式算出（**上限不是目标**） |
| 参考图 | **用**，在「参考：」里按上传顺序列出**文件名**；**人物外观由参考图锁定，不另写外观文字** |
| 字幕 / BGM | **无字幕、无 BGM**（不许出现） |
| 转场 | **硬切 / 动作接动作** |
| 场景结构 | **按剧本来**，不自行发挥 |
| 产品植入 | **剧本里是什么就是什么**，不扩写卖点、不编价格 |
| 重点戏 | 不区分 |
| 总时长目标 | 不设限，按剧本自然算 |
| 焦距 | **不写**（只写景别；实测「近景＋85mm」会被执行成中远景） |
| 提示词长度 | **不设限** |

# §2 绝对不能改剧本（最高优先级）

**你的任务是把剧本"翻译"成分镜，不是改剧本。剧本原文一个字都不许动。**

**不许改**
- **台词**：一字不改、不增不减、不润色、不翻译、不调顺序、不合并句子，**标点也照抄**
- **剧情**：不新增事件、不删情节、不改因果、不改结局
- **场景**：不换地点、不并场、不拆场、不改时间（清晨就是清晨）
- **人物**：不改名字、不改关系、不改年龄、不新增人物
- **产品**：剧本怎么写就怎么用

**可以加（只限镜头执行层面）**
- 分镜技术信息：景别、运镜、机位、画面描述（含前后景虚实）、光影、色调、构图
- 台词行里的表演指示：`（台词节奏）`、`看向某某`、`|0.3|` 停顿标记——**这些是给 AI 的指令，不算台词**
- 衔接动作：走近、接住、转身、递过去等不改变剧情的小动作

**判断标准**：会改变"观众看到的事件"→ 不许加；只是让同一事件拍得更清楚 → 才许加。
**剧本本身有矛盾时**（前后不一致、缺场景、台词与场景对不上）：**先不生成，先提醒用户**，等确认后再继续；不许自己补情节或改设定。

# §13 参考素材引用（官方规则）

- 素材按上传顺序在「参考：」里列出**文件名**（如 `林秀兰围裙.png`）。
- **平台会自动给参考图编号（`<Picture N>`），交付物里不用写它**——写了是多余，还可能和平台实际编号对不上。
- **编号必须和上传顺序一致**，否则会引用错素材。
- 同一素材可多处引用，但**用途要切清楚**（形象／动作／场景／光线各引一次）。
- **一个单人设定图＝恰好一个角色**；多素材时**一人一图**优先分配。
- **主体锁定**要显式写：`主体锁定：傅言深、阿萍、商场取餐区`。
- **多主体一致性**：不同素材的用途在提示词里切开，避免特征串位；三人以上时写明**不能共用同一张脸，不能长得像双胞胎**。
