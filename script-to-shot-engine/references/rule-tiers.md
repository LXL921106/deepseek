# 规则分级与判定权

> **本文件是本技能所有规则的唯一索引。** 任何规则必须归入下面四级之一，并绑定判定者。
> 依据：创作判断交给创作者，确定性判断交给脚本，语义判断交给审查者。**三者混用会让模型无法区分「违反就废片」和「建议如此」**——那正是规则越写越多、却越来越不生效的根因。

## 四级

| 级别 | 含义 | 判定者 | 能否阻断交付 |
|---|---|---|---|
| `structural_invariant` | 本地可证明的矛盾：引用／ID／算术／逐字比对／显式状态 | **脚本** | ✅ 能 |
| `reviewed_invariant` | 语义义务，需引用证据判定 | **审查者** | 需证据，不自动阻断 |
| `craft_default` | 通常有帮助的做法；**创作者说明理由即可覆盖** | **创作者** | ❌ |
| `taste_option` | 表达选择 | **创作者** | ❌ **不得单独阻断** |

### 三条硬规矩

1. **脚本的阻断级别必须与本表一致。** 把 `craft_default` 当阻断执行是**差两级**。
2. **never 用固定词表或形容词比例阻断交付。** 只有本地可证明的东西可阻断：模板占位、`@引用名`、ID、算术。
3. **通用数值（时长／字数／镜头数／比例）不得作为硬约束。** 它们只进入**项目档案**，由创作者确认后成为该项目的"已接受值"；脚本只能校验"是否等于已接受值"，不能自己发明阈值。

## structural_invariant（脚本可阻断）

| ID | 规则 | 校验方式 |
|---|---|---|
| `TIM-01` | 分镜标题符合 `分镜N（起-止秒）：`；首镜从 0 秒开始 | 正则 |
| `TIM-02` | 相邻分镜默认首尾相接，不留空；末镜结束在 Clip 总时长 | 算术 |
| `TIM-03` | 除注明「有意重叠」外，相邻分镜不得重叠 | 算术 |
| `TIM-04` | Clip 声明的总时长 = 末镜结束时间 | 算术 |
| `DIA-01` | 剧本每句台词（去标点后逐字）必须出现在正文中，允许拆镜后按顺序拼接还原 | 逐字比对 |
| `DIA-02` | 被拆开的台词，其各段在同一说话人的台词流中必须**连续**，中间不得夹其他台词 | 序列比对 |
| `DIA-03` | 以逗号／破折号结尾的台词段，其后继段必须继续同一句剧本原句 | 序列比对 |
| `DIA-04` | 同一句台词不得出现在两个不同的 Clip | 重复检测 |
| `DIA-05` | 台账「落点」列不得为空 | 表结构 |
| `AST-01` | 正文所有 `@引用` 必须在「美术资产对照卡」登记 | 集合比对 ｜ **待实现——尚无脚本，不要声称它被阻断** |
| `AST-02` | 正文不得用 `图N`／`图片N` 指代人物（必须写人物名） | 正则 |
| `FMT-01` | 交付物必须是「单元 N + 镜头 N \|」格式，或明确的旧格式；两者都不是即报错 | 格式守卫 |
| `FMT-03` | 每个单元必须以 `单元 N` **单独一行打头** | 格式守卫 |
| `PRJ-01` | 项目档案中创作者已接受的值（如「开场用可见画面」「无背景音乐」）在交付物中被满足 | 值比对 ｜ **待实现——尚无脚本** |
| `CNT-05` | 锚点清单＋人物初始位置齐备；角色名不重复、不出现未登记的人 | 解析＋集合比对 |
| `CNT-06` | 每个镜头写「出场人物：…」，且必须是本单元「人物：」行登记过的角色 | 逐镜集合比对 |
| `CNT-08` | **越肩镜必须写「同人声明」**：前景的〈角色名〉与画面里的〈角色名〉是同一个人、本镜只出现这一次 | `check_cast.py` 解析＋关键字 |
| `CNT-09` | 同一镜的「出场人物」不得重复列出同一个角色 | 逐镜去重 |
| `TIM-05` | 时长算式算术自洽：字数÷语速向上取整到 0.5s，加缓冲后等于该镜时长 | `check_units.py` 算术 |

> `PRJ-01` 是通用出口：任何"本项目的固定选择"都记进项目档案，然后由脚本按值校验。**不要为每一个项目选择新增一条规则。**

## reviewed_invariant（审查者引用证据）

| ID | 规则 |
|---|---|
| `DIA-06` | 连贯台词不得被无台词分镜隔断（脚本可标记"同一说话人两段台词间夹了无台词分镜"，判定交审查者） |
| `DIA-07` | 长台词的拆分点必须落在自然停顿处（句末或明显逗号） |
| `SHT-01` | 景别—内容兼容：分镜写的内容必须能被它自己写的**景别**拍到 |
| `SHT-02` | 镜头目的必须是**剧情层**信息增量，不是"交代站位／距离／环境／姿态" |
| `SHT-03` | 「并行」只限说话人本人的动作；他人的反应另起分镜 |
| `AUD-01` | 需要画外音的分镜，画面里的人不得有口部动作（脚本可**提示**命中，永不阻断） |
| `CNT-01` | 物理锁死五项（持握手／朝向／距离／接触点／步速）在每个分镜可查 |
| `CNT-02` | 跨单元 承接上一段末态 |
| `CNT-07` | 走位只改顺序不改人数；人物走动写在发生它的那个分镜里 |
| `TAS-01` | 内容—时长匹配：分镜时长显著大于「台词＋动作所需」时，必须在镜内写明理由（凝滞／等待／压迫感） |
| `DIA-12` | **台词与动作同期开始**——「边说话」之前排的动作会被模型先执行完，台词整段推后（实测 0.73／1.50／1.74 秒每镜） |
| `DIA-13` | 停顿**必须写成 `\|N\|` 行内标记**落进台词里——只写「逗号后 0.3 秒」这种描述句模型不执行（实测停在 1.40 秒） |
| `DIA-15` | **别把「算式语速」当演出指令**：模型看不见 `字数÷语速` 里的数字，只看见台词行里的「语速缓慢／字字清晰」。**默认不写"缓慢"，永不写"字字清晰"** |
| `DIA-14` | 语速档**不得超过实测自然语速**（5.6—6.1 字/秒）——提高档位不会让模型说快，只会把窗口收得比实际需要窄，挤成赶字／吞字／台词侵占下一镜 |
| `AFX-01` | 画面描述里不得写心理感受（"她感到悲伤""他很感动"）——必须写成看得见的身体/脸（脚本**只提示**，词表不得阻断） |
| `AFX-02` | 不得用无参照方位词（"左边/右边/旁边/对面"）——必须写"锚点名＋画左/画中/画右"（脚本**只提示**，词表不得阻断） |

## craft_default（创作者说明理由即可覆盖）

| ID | 规则 |
|---|---|
| `DIA-08` | 说话人的动作与台词**同期开始**；不先做完动作再另起一镜说话 |
| `DIA-09` | 给台词一个**可见的起点锚**（用物理事件替代"同时"这类抽象词） |
| `DIA-10` | 音频桥是最后手段：跨度 ≤1 秒、显式写听方口型闭合、听方零口部动作 |
| `DEN-01` | 只交代场面信息的无台词分镜，尽量并入相邻的有台词分镜（倾向值，非阈值） |
| `DEN-02` | 承载剧情变化的无台词分镜，一段里不要多（倾向值，非阈值） |
| `DEN-03` | 台词说完后不要长时间留白；分镜时长与内容量相称 |
| `AUD-02` | 无台词分镜在本镜内写本镜音效（集中音效块不会覆盖它们） |
| `AUD-03` | 音效服务画面因果；按声音层级写 |
| `MST-01` | 微动作只写画面上读得出来的（视线／持物／姿态／手部） |
| `PERF-01` | **算式语速**参考（只算时长，模型看不到）：正常 6 字/秒、快 7、慢 5.5；情绪在同一人基线上浮动。**这不是演出指令**（见 `DIA-15`） |
| `PRJ-02` | **先分镜，后装箱**：整场戏的镜头先全部列完（**不看 15 秒**），再贪心装箱成单元。**一轮默认输出 3—5 个单元**，不是每次一个 |
| `PERF-02` | 短镜头台词量不要超过镜头能容的量 |
| `CAM-01` | **不写焦距，只写景别**——实测「近景＋85mm」会被执行成中远景（写了尺寸词又写 mm，模型要在两个尺寸之间调和，结果取松的那个） |
| `CAM-04` | 交付物正文里不得出现焦距（`\d+mm`） |
| `CAM-02` | 每个分镜只留一个主要运镜；组合运镜分时间段 |
| `CAM-03` | 开场尽早进冲突，不用空镜建立 |
| `MOD-01` | 按输入模式（T2V／I2V／首尾帧／R2V／视频编辑）调整写法 |
| `MOD-02` | 平台不支持的能力按降级表处理 |
| `NEG-01` | 负向清单只留本 Clip 最相关的 3–6 条 |

## taste_option（不得单独阻断）

| ID | 规则 |
|---|---|
| `TAS-02` | 分镜数量 |
| `TAS-03` | 分镜节奏与长度分配 |
| `TAS-04` | 强制构成比例（同框／说话人／微动作的数量） |
| `TAS-05` | 交替硬规则 |
| `TAS-06` | 凝滞分镜的时长 |
| `TAS-07` | 叙事弧四段（建立→阻力→选择→收束） |
| `TAS-08` | 场景模式（动作／对峙／混合） |
| `STY-01` | 风格三件套（画风＋色调＋情绪）与六槽位风格锁定 |
| `FMT-02` | 台账表的具体列与排版 |

## 项目档案（已接受值）

这些不是规则，是**本项目确认过的选择**。每次开工先读，脚本按值校验：

| 键 | 含义 | 示例值 |
|---|---|---|
| `title` | 剧名 | `爱与陪伴` |
| `target_model` | 目标模型 | `Wan 3.0` |
| `aspect_ratio` | 画幅 | `9:16` |
| `max_shot_seconds` | 单次生成最长时长 | `15` |
| `no_background_music` | 全程无背景音乐 | `true` |
| `open_with_visible_shot` | 开场第一镜必须是可见画面 | `true`（中景或全景） |
| `allow_intentional_overlap` | 允许注明后的时间重叠（音画分离／并行） | `true` |
| `speaker_shot` | 说话人镜的机位；`frontal_single` = 正脸单人近景（clean single）。**无台词分镜允许侧面** | `frontal_single` |
| `on_screen_cast_per_shot` | 每个镜头写「出场人物：…」，且必须是本单元「人物：」行登记过的角色 | `true` |
| `addressee_in_every_shot` | 每个含台词的分镜必须写「对〈人物名〉」 | `true` |
| `upstream_frozen` | 上游 Clip 只读；发现上游有错必须停下问用户 | `true` |
| `generated_is_readonly` | 已生成的提示词快照只读 | `true` |

**模板与脚手架**：`templates/project/` ＋ `scripts/new_project.py`。建好的工作区里，`01-档案/项目档案.md` 就是这张表的实体，`01-档案/结尾状态链.md` 承载逐 Clip 的结尾状态（人物／姿势／持物／位置／朝向）。

## 降级记录（本次重构从"硬约束"降下来的）

| 原措辞 | 原级别 | 现级别 | 理由 |
|---|---|---|---|
| 无台词分镜总时长 ≤3 秒 | 硬约束 | `DEN-01` craft_default | 通用数值配额；与项目动作预算和创作者权威冲突 |
| 剧情型无台词分镜一段 ≤2 个 | 硬约束 | `DEN-02` craft_default | 同上 |
| 单个说话人镜 ≤ Clip 时长一半 | 硬约束 | `DEN-03` craft_default | 同上 |
| 分镜时长 ≤ 台词＋动作 的 2 倍 | 硬约束 | `TAS-01` reviewed_invariant | "是否写明理由"是语义判断，脚本判不了 |
| 近景只装一个人 | 硬约束 | `SHT-01` reviewed_invariant | 需看画面内容，语义判断 |
| 写焦段（`焦段 85mm（近景）`） | 硬约束（要求写） | **`CAM-01` 反过来：禁止写焦距** | 写了尺寸词又写 mm，模型取松的那个，实测把近景执行成中远景 |
| 听方镜不得写口部动作 | 硬约束 | `AUD-01` reviewed_invariant | **固定词表不得阻断交付**；脚本只能提示 |
| 「同一镜内」不得堆他人动作 | 硬约束 | `SHT-03` reviewed_invariant | 需判断"是否说话人本人" |

> 降级不等于删除。这些知识仍在，只是**不再与"违反就废片"混在同一层级**。

## 脚本

| 脚本 | 覆盖 | 线路 | 用法 |
|---|---|---|---|
| `scripts/check_units.py` | `TIM-01`–`TIM-05`、`FMT-01`／`FMT-03` | **Wan 新格式（本线）** | `python check_units.py --delivery 交付物.md` |
| `scripts/check_cast.py` | `CNT-05`–`CNT-09`、`FMT-01`／`FMT-03` | **Wan 新格式（本线）** | `python check_cast.py --delivery 交付物.md` |
| `scripts/check_dialogue.py` | `DIA-01`–`DIA-05`、`AST-02` | **两条线通用** | `python check_dialogue.py --script 剧本.md --delivery 交付物.md [--ledger 台账.md]` |
| `scripts/check_timeline.py` | `TIM-01`–`TIM-04` | **仅历史旧格式交付** | `python check_timeline.py --delivery 交付物.md [--clip-seconds 15]` |

**格式守卫（`FMT-01`／`FMT-03`）**：`check_units.py` 与 `check_cast.py` 发现交付物既不是「单元 N」也不是「### Clip NN」时**直接报错**（`FMT-01`）；是单元格式但**缺 `单元 N` 标题行**也直接报错（`FMT-03`）。**都不静默通过。**
> 注意 `FMT-02` 是另一条：台账表的列与排版（第三层，不阻断）。**新 ID 一定要先在本表里查重**——`selfcheck` 的 `SC-11` 现在会查。
> 教训：`check_timeline.py` 曾因找不到 `### Clip NN` 而一个分镜都没读到，把一份漏了 6 秒的提示词判成"通过"。**"读不到内容"必须和"内容没问题"区分开。**

**`check_timeline.py` 已不在主线上**——新格式的时长由「时长计算」推导，由 `check_units.py` 承担。保留它只为**历史旧格式交付**（老产物仍然要能审）。

DSH 环境用捆绑 Python：`~/.dsh/dsh-runtimes/*/dependencies/python/python.exe`。

**脚本红了就不要交付**——这正是"台账/脚本"比"散文检查项"强的地方：空格和缺口就在那里，一眼可见，不依赖谁声称自己检查过了。
