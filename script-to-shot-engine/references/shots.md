# §6 镜头规则

**5.1 一个镜头一个视觉重点**：不是"一个动作一个镜头"，是"一个镜头观众只看一个地方"。
✗ `他尝山菌，眼睛一亮，说"香！真香！"`（AI 不知看嘴、眼睛还是山菌）
✓ 拆三镜：①放进嘴里嚼 ②眼睛睁大瞳孔一亮 ③边嚼边惊喜地说
**切镜时机**：视觉重点变 / 动作变 / 情绪变 / 有人说话或有人反应。

**5.2 动作与台词同时**：写"**边X边说**"。
✗ `抬手扫过山货。台词："这些我全要了。"`（AI 理解成先扫完、站定、再开口）
✓ `手从左到右扫过摊面，边扫边说` + 台词。

**5.4 双对比切镜（`SHT-05`）**：**每次切镜必须同时改变「景别」和「机位性格」。**

- 景别阶梯：`大远景 → 远景 → 全景 → 中全景 → 中景 → 中近景 → 近景 → 特写 → 大特写`
- 机位性格：`固定 ｜ 手持 ｜ 稳定器跟拍 ｜ 摇臂 ｜ 航拍 ｜ 越肩`

✗ `中景手持 → 近景手持`（机位性格没变，剪辑会"平"）
✓ `中景手持 → 特写固定`

**目的**：让观众清楚自己**被换了个位置**看。只换景别不换机位性格，两个镜头会糊在一起。

**5.5 默认已经在进行中（in medias res，`SHT-06`）**：镜头落下时，事情**已经在发生**。不写"开始做 X"。

- ✗ 「她坐下，然后开口说…」→ 模型会先坐完再开口。**实测每镜台词推后 0.73／1.50／1.74 秒，就是这么来的。**
- ✓ 「她正说着，边把右手收回桌沿」→ 镜头落下时话已经在说。

只有剧本明确要求"先是…后是…"时才写顺序动作。

**5.3 景别**（**不写焦距**）

| 看什么 | 景别 |
|---|---|
| 脸/情绪 | 近景 CU / 大特写 ECU |
| 动作+人 | 中景 MS |
| 环境+人 | 全景 Wide |
| 道具/细节 | 大特写 ECU |

可用景别：大远景→远景→全景→中全景→中景→近景→特写→大特写，**每镜必标**。情绪越强景别越紧，动作越大景别越松。**每组至少含** 1 大景别（定场）+1 特写（情绪锚点）+1 中景（信息交代）。**禁止连着三个近景**。

> **为什么不写焦距**：实测「近景｜85mm」被执行成中远景（把不该入画的人也拍进来，进而和前景人物重叠成像）。**景别词已经决定了虚实与取景范围**，再写 mm 只会互相打架。

**5.4 景别怎么接**：相邻景别不硬切（中景接近景像放大缩小）｜隔一别更顺（全景直切特写，跳过的当过渡层）｜两极镜头可冲击（特写切全景制造情绪落差）｜对话戏前松后紧（前半中景，后半近景/特写）｜单元衔接：上单元结尾特写→下单元开头优先全景。

**5.5 运镜**：固定 / 慢推 / 慢拉 / 摇 / 移 / 跟 / 横移 / 竖移 / 俯仰 / 轨道 / 升降 / 手持晃动。**每镜必标，一镜只写一个**；整组**至少 3 种**。写"慢推"不写"瞬间推进"。对话段优先固定；行走/动作跟拍或轨道；情绪爆发推镜；离别/收尾拉远。

**5.6 9:16 构图**：人物居中偏下，头顶留 1/10，原生竖屏，左右留边不贴边。

**5.7 开场**：第一镜直接台词或大动作，不要空镜建立。内景不要路人；外景背景虚化路人可以。

**5.8 画面内容（看图说话）**：写屏幕能看到的东西。
✗"她感到一阵悲伤" ✓"她眼眶泛红，嘴角微颤，一滴泪从右眼滑落"
✗"他很感动" ✓"眉头皱起，下巴抬高，后退半步"
每镜须含：人物位置/姿态（引锚点）、光线方向、背景元素（引锚点）、**前后景与虚实（直接写进句子里）**、关键细节。**禁止**"镜头给到""我们看到"类元描述。人物位置变化必须写锚点路径过渡。

**5.9 衔接**：动作接动作、视线接视线、声音接画面；前镜落幅即后镜起幅。不许"突然跳到"，跳切须标原因。
