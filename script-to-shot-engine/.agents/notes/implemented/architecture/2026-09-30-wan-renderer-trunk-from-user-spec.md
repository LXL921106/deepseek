# Agent Note: Wan 渲染器主干换成用户自己的规范

Status: implemented

## Problem

技能里的 Wan 分支是自己长出来的：22 条规则、37 条最终检查、空间关系用「空间站位」散文描述。

实测暴露了两个**同源**缺陷：**同一角色在一帧里出现两次**（v14 两个苏晓雯 → 单元11 两个阿萍）。排查发现根因不在规则措辞，在**载体**：用相对方位的散文写空间，**可以互相矛盾**，而模型不会报错——它会多造一个人来同时满足。

同时用户自己有一份《AI短剧分镜与提示词规范》（258 行，网页版长期使用、稳定），已经有：**锚点系统**（人物位置引锚点、禁无参照方位词、单人镜背景不得有他人）、**时长算式＋贪心装箱**、**台词三套句式**（含"看向对象"）、**看图说话**（不写心理感受）、**手机屏专项**。

## Decision

**Wan 分支的主干整段换成用户那份规范**，自研那套退位。

- `references/wan-renderer.md` ＝ 规范全文 ＋ §11 台词逐句回勾表 ＋ §12 三层门禁 ＋ §13 官方素材引用 ＋ §14 参数降级 ＋ §15 故障排查。
- 新增 `scripts/check_units.py`：时长算式自洽 · Σ镜头＝声明总秒数 · 6—15 秒区间 · **`FMT-01` 格式守卫**。
- `scripts/check_cast.py` 重写为 锚点／出场人物／**同人声明**（`CNT-05..09`）。
- `SKILL.md`：「空间站位」整节 →**空间锚点**；「在场人物」→**出场人物**；`FMT-01` 与 `check_timeline.py` 的归属写清。
- **删掉**：空间站位、信息密度配额、内容—时长匹配、单个说话人镜 ≤ 半 Clip、37 条最终检查、焦距。

本次同时落地的四条实测修正：

1. **不写焦距**（只写景别）——实测「近景＋85mm」被执行成中远景，把不该入画的人也拍进来，进而和前景人物重叠成像。
2. **人物外观由 `<Picture N>` 锁定，不再写文字设定**——有参考图时文字设定会跟图打架。
3. **台词行加 `|N|` 停顿标记 ＋ 默认停顿**（逗号 0.3s／句号 0.5s）——实测模型在句读处自行停 1.4—2.5 秒，把 43% 的时长吃掉。
4. **越肩镜必写「同人声明」**——不写声明时，前景的听方会被当成第二个人（实测两次）。

## Alternatives considered

- **继续在现有 22 条规则上打补丁** —— 最强理由：改动最小，历史证明它确实堵住过空镜、动作台词串行等问题。不采用：6 个版本的经验是**每加一条"必须"就在别处开一个新洞**，规则到 37 条自查时等于没有自查；更关键的是，本次两个同源缺陷都是**"散文写空间"这个载体的产物**，继续在散文里加禁令是治载体而不是治病。
- **只吸收规范的锚点系统，其余保留自研规则** —— 最强理由：锚点是关键修复，其余规则已被实测验证。不采用：混两套术语（锚点＋空间站位）会让模型读到哪份按哪份走，**等于两套都不生效**；主干只能有一套。
- **连门禁脚本也换掉，全用规范** —— 最强理由：一致性最好。不采用：规范是纯散文、没有可执行校验；`check_units.py`／`check_cast.py` 是本次唯一能把"漏了 6 秒""越肩未声明"变成**可自动阻断**的东西，必须保留。

## Consequences

- **收益**：空间描述从"可矛盾"变成"**不可能矛盾**"（锚点 ＋ 无参照方位词禁令）；时长从"估"变成"算"，并**按算出值设平台时长**（不再为填满 15 秒拉长停顿）；同人声明把两次实测事故变成可脚本拦截。
- **代价与已知上限**：
  - `SKILL.md` 的**默认输出模板仍走 Seedance 线**（带时间戳与焦距），与 Wan 主干并存。**Seedance 线是否也该去掉焦距，尚无实测依据**——留给人工决定。
  - `AST-01`、`PRJ-01` 标为 structural 但**尚无脚本**，已在 `rule-tiers.md` 标注「待实现」。
  - `cases/01`、`cases/03` 仍是旧格式夹具，靠 `skip_checkers` 声明不适用。
  - **规范本身没有"停顿"这一格**——`|N|` 与默认停顿是技能对规范的增补，用户桌面上那份文档没有同步（用户已明确：技能版为准，桌面那份只作参考）。
