# 04-实测

**实测是唯一的真凭据。** 提示词写得对不对，最终看片子。

每测一段，留一行：

| Clip | 提示词写的台词区间 | 实测台词区间 | 偏差 | 无台词尾段 | 语音电平 | 结论 |
|---|---|---|---|---|---|---|

## 测什么（用 `scripts/measure_clip.py`）

| 指标 | 怎么来 | 看什么 |
|---|---|---|
| 时长／分辨率／帧率 | `ffprobe` | 有没有被平台改 |
| 台词实际起止 | `silencedetect` | **和提示词写的时间戳差多少** |
| 尾段电平 | `volumedetect` | 是"写了无台词"还是"被截断" |
| 抽帧接触表 | `fps=1` + `tile` | 口型、姿势、站位是否按写的走 |

## 与上一轮对照

**每次都要比：这一轮是新问题，还是老问题复现？** 没有对照就没有"进步/退步"。

结论分三类落到 `05-复盘/`：

- **规则错了** → 改技能，并加一个能证伪它的夹具
- **规则没错但没被执行** → 是门禁的缺口（要做成脚本）
- **创作者偏好变了** → 改 `01-档案/项目档案.md`，**不要改技能**
