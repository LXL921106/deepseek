# 05-复盘

每一轮生成后，把发现写在这里——**一类一条，不要写流水账**。

## 三类去处（对应到具体的动作）

| 发现的性质 | 去哪 | 具体动作 |
|---|---|---|
| **规则错了或漏了** | 技能 | 改 `references/`，**并加一个能证伪它的 `evaluations/cases/NN-*/` 夹具** |
| **规则对但没被执行** | 门禁缺口 | 做成 `scripts/` 里的脚本（能算的）或写进门禁第二层（要判断的） |
| **创作者偏好变了** | 项目档案 | 改 `01-档案/项目档案.md`，**不要改技能** |

## 一条记录的格式

```text
## YYYY-MM-DD · 组 N
现象：      实测看到什么（附数字或截图路径）
是老问题吗： 对照 04-实测/ 上一轮 → 新 / 复现
归到哪一类： 规则错 / 门禁缺口 / 偏好变了
动作：      具体改了什么，或"已问用户，待定"
```

**不要只写"这次好多了"**——那不是记录，是感觉。
