# 02-交付

每段一组三件：

```text
ClipNN-交付物.md      提示词全文（门禁脚本吃这个文件）
ClipNN-台账.md        台词逐句回勾表（落点为空即为漏句）
ClipNN-门禁.txt       两个脚本的输出（留证：红了什么、绿在哪）
```

## 规矩

- **脚本红了不得交付。** 改到绿为止，把过程留在 `门禁.txt` 里。
- 交付物一旦**拿去生成**，就**冻结**这份文件（见项目档案 `generated_is_readonly`）。
- 要改已生成段的写法 → **新开一份 `ClipNN-交付物-v2.md`**，不要原地改。
