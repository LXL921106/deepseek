# 03-生成

放**实际拿去生成的东西**和**回来的东西**：

```text
ClipNN-提示词快照.md     当时真正贴进平台的提示词（原样，不许再改）
ClipNN-出片.mp4          平台回来的视频
```

## 为什么快照要单独存一份

`02-交付/` 里的交付物可能后来被**改动**过；这份快照不会。

**出片 + 快照** 合起来才是"这一段当时到底发生了什么"的完整证据——**实测（`04-实测/`）比对的就是这两样**。

## ⛔ 已生成的快照只读

改它的文本**不会改变已成片**，只会让文本和成片不一致。

真要改 → **先问用户是否重新生成**，得到确认后新开 `-v2`。
