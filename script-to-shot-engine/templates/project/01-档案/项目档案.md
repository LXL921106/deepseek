# 项目档案 · {剧名}

> **开工前第一件事：读这份。**
> 这里记的是**创作者已确认的值**，不是建议。要改值就改这里——**不要在下游临时决定**，否则下一个会话又不知道。
> 档案里的值**优先于**技能里的 `craft_default`。

## 一、基础参数

| 键 | 值 | 含义 |
|---|---|---|
| `title` | | 剧名 |
| `target_model` | Wan 3.0 | 目标模型，决定读哪个渲染器 |
| `aspect_ratio` | 9:16 | 画幅 |
| `max_shot_seconds` | 15 | 平台可设上限（秒） |
| `min_shot_seconds` | 6 | 平台可设下限（秒） |
| `duration_source` | 算式 | 时长由「时长计算」逐镜算出后求和，**按算出值设平台时长**；**15 秒是上限不是目标** |
| `no_background_music` | `true` | 全程无背景音乐 |
| `open_with_visible_shot` | `true` | 开场第一镜必须是**可见画面**（中景／全景），**禁纯黑** |
| `allow_intentional_overlap` | `true` | 音画分离或动作台词并行时，允许注明后时间重叠 |

## 二、镜头偏好

| 键 | 值 | 含义 |
|---|---|---|
| `speaker_shot` | `frontal_single` | **拍正在说话的人时**：机位沿该人物的**面向轴线**、画面里**只装他一人**、给**正脸单人近景**（clean single）。侧脸／过肩**只留给听方反应镜、双人同框，以及无台词分镜**（无台词时侧一点更有回避感）。要用侧脸表现说话人的回避或对立，必须写明理由。 |
| `on_screen_cast_per_shot` | `true` | **每个镜头写「出场人物：…」**，且必须是本单元「人物：」行登记过的角色。 |
| `addressee_in_every_shot` | `true` | **每个含台词的分镜必须写对白对象**：`沈志远（对林秀兰，语速急促）开口说："…"`。目的是让听方反应镜该拍谁一目了然，多人场景不会"对着空气说"。 |

## 三、工作流约定（跨会话，别丢）

| 键 | 值 | 含义 |
|---|---|---|
| `upstream_frozen` | `true` | **上游只读。** 写第 N 个 Clip 时，第 1..N−1 个 Clip 的文本与生成产物都**不可回改**。发现上游有错 → **停下来说明冲突并问用户**，不得静默改。 |
| `generated_is_readonly` | `true` | **已经拿去生成的提示词快照只读。** 改它的文本不会改变已成片，只会让文本与成片不一致。要改必须先问用户是否重新生成。 |

**为什么这两条写死**：实测发生过——写 Clip 9 时发现 Clip 8 的结尾（人物坐下）不对，回头改了 Clip 8，而 **Clip 8 已经生成过了**。文本变了、成片没变、两边对不上。

## 四、人物与声线

| 人物 | 资产名 | 声音特征（**只写音色**） | 标志物 |
|---|---|---|---|
| | | | |

**声线只写音色，不写语速**（`DIA-15`）。语速写在**每句台词的 `台词节奏`** 里，默认「正常」。

**语速基准**（只用来算时长，模型看不到）：**标准 4 字/秒** · 慢 3 · 快 5。**含表演余量**——实测模型纯发声 5.6—6.1，比 4 快；**差额留给表演，不要收紧**。

> ⚠️ **这个数字不是演出指令。** 把档位从 3 提到 7/8/9 **不会让成片变快**——
> 模型只看得见台词行里的形容词。实测过：档位提了一倍多，成片一点没变，因为台词行里
> 「语速缓慢」「字字清晰」一个字没改。

## 六、本项目的固定格式约定

- 分镜标题：`分镜N（起-止秒）：`
- 台词：`台词：〈人物名〉看向〈对白对象〉（〈台词节奏，默认"正常"〉）：「〈原句，停顿写成 |N| 行内标记〉」`
- 无台词镜：**本镜音效写在镜内**
- 结尾状态链：见 [`结尾状态链.md`](结尾状态链.md)，**一行一个 Clip**
- 交付顺序：美术资产对照卡 → 全局风格锁定 → **台词逐句回勾表** → 视频生成提示词 → 生成前提醒
