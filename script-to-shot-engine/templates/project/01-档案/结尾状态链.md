# 结尾状态链 · {剧名}

> **一行一个组。** 写完一个组 就把它的结尾状态补一行并**冻结**。
> 写第 N+1 个 组 前**先读第 N 行**，交付里必须逐字承接。
> 已「生成」的 组 更是只读（见项目档案的 `generated_is_readonly`）。

## 填法

| 列 | 写什么 |
|---|---|
| **已生成** | `✅ 2026-09-30` 或留空。**填了就不再回改这一行对应的 组。** |
| 人物 | 本组 结束时**在场的人** |
| 姿势 | 坐／站／蹲／半起／转身 —— **这是最容易出错的一列** |
| 持物 | 手里拿着什么、在**哪只手** |
| 位置 | 在画面哪一侧、与谁相距几步 |
| 朝向 | 面向画面哪个方向 |
| 备注 | 视线、伤势、情绪落点等下一段必须接住的 |

## 表格

| 组 | 已生成 | 人物 | 姿势 | 持物 | 位置 | 朝向 | 备注 |
|---|---|---|---|---|---|---|---|
| 01 | | | | | | | |

## 写第 N 个 组 之前，自查三句

1. 第 N−1 行的**姿势**是什么？我这一个组 的第一镜接的是不是这个姿势？
2. 第 N−1 行的**持物与手**是什么？有没有换手？
3. 第 N−1 行的**朝向／位置**是什么？有没有不解释的位移？

**任何一条接不上 → 先问，不要回头改上一行。**
