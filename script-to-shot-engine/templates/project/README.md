# 项目工作区 · {剧名}

## 六个目录干什么

| 目录 | 放什么 | 谁写 |
|---|---|---|
| `00-输入/` | 剧本、人物资产图、场景图、参考片 | 你 |
| `01-档案/` | **项目档案** ＋ **结尾状态链** | 你确认，Agent 读 |
| `02-交付/` | 每段的 `交付物.md`、`台账.md`、门禁报告 | Agent |
| `03-生成/` | 实际出片 ＋ **当时用的提示词快照** | 你放出片，Agent 存快照 |
| `04-实测/` | ffprobe / silencedetect 结果、前后对照表 | Agent |
| `05-复盘/` | 每轮发现 → 缩成 `evaluations/cases/` 夹具，或降级进档案 | Agent |

## 一轮怎么走

1. **开工前** — Agent 读 `01-档案/项目档案.md`（参数、镜头偏好、工作流约定）
2. **写第 N 个 组 前** — Agent 读 `01-档案/结尾状态链.md` 的**第 N−1 行**
3. 产出落进 `02-交付/`
4. **跑门禁** — `check_groups.py` ＋ `check_dialogue.py`，**红了不得交付**。
5. 你去平台生成；出片和**当时用的提示词**都进 `03-生成/`
6. Agent 实测 → `04-实测/`（与上一轮对照：是老问题还是新问题）
7. 有发现 → `05-复盘/`

## ⛔ 两条不能碰的线

1. **上游只读** — 写 组9 时**不许回头改 组8**。发现上游有错 → **停下来问用户**，不得静默回改。
2. **已生成的快照只读** — 改它的文本**不会改变已成片**，只会让文本和成片不一致。

> 这两条来自一次实测：写 组9 时发现 组8 的结尾（人物坐下）不该出现，回头改了 组8 —— 而 **组8 已经生成过了**。文本变了、成片没变、两边对不上。
